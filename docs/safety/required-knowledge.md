# Required Knowledge

## Overview

The background knowledge a person needs before operating the physical
Spot system, and where to get it on this site.

## Purpose

Operating Spot safely does not require being a ROS 2 expert, but it
does require enough familiarity with the tools involved that an
unexpected situation does not turn into a confused one.

## Before touching the physical robot

- **ROS 2 fundamentals** — nodes, topics, services, actions, launch
  files. See [ROS 2](../ros2/index.md). Spot's own interfaces (topics,
  services, actions) are documented in [System
  Architecture](../architecture/index.md), but they will make much more
  sense with the general concepts first.
- **A working development environment** — Linux, a terminal, Git. See
  [Getting Started](../getting-started/index.md).
- **This site's Safety and Prerequisites section in full** —
  [Safety Principles](safety-principles.md),
  [Emergency Stops](emergency-stops.md), [Operating
  Area](operating-area.md).
- **Sign-off from a trained team member.** This site is a technical
  reference, not a substitute for in-person training on ALeRT's actual
  procedures and current hardware state.

## System context

This page exists so [Safety Principles](safety-principles.md) and
[Operating Spot](../operating/index.md) do not need to re-explain ROS 2
or basic Linux use inline — they assume it.

## Verification

Not applicable — this page states a prerequisite, not a system
behavior.
