# Rescue Challenges

## Overview

A short summary of the RoboCup Rescue League's challenge categories, as
recorded by the former ALeRT tutorial.

:::{admonition} Historical snapshot
:class: note

This page reflects the state documented by the former ALeRT tutorial,
where it was a brief, single-paragraph summary. It is preserved at the
same length here rather than expanded with invented detail — see
[RoboCup Rescue](robocup-rescue.md) for the fuller category-by-category
description from the same source.
:::

## Description

The RoboCup Rescue League contains the following challenges: readiness,
maneuvering, mobility, dexterity, and exploration.
