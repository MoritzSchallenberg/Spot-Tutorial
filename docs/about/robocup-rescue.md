# RoboCup Rescue

## Overview

The RoboCup Rescue League challenge categories, as documented by the
former ALeRT tutorial, based on the 2019 rulebook and a subsequent
"smaller teams" ruleset update.

:::{admonition} Historical snapshot
:class: note

This section reflects the state documented by the former ALeRT
tutorial. Rulebook versions and task details change from year to year;
the statement "tasks for 2022 not published yet" was accurate when
originally written and is preserved here as a historical record, not as
a statement about the current competition year. Consult the current
official RoboCup Rescue League rulebook for present-day rules.
:::

## The competition simulates disaster response

A robot must traverse an arena built to resemble a collapsed structure
and demonstrate capability across several categories, which change from
year to year.

## Challenges (2019 rulebook)

:::{figure} ../_static/images/history/arena3.png
:alt: The RoboCup Rescue League competition arena, 2019 rulebook.

The competition arena, 2019 rulebook.
:::

### Maneuvering and mobility

Various surfaces. Obstacles.

:::{figure} ../_static/images/history/maneuvering.png
:alt: An obstacle and surface setup from the maneuvering and mobility challenge.

An obstacle/surface setup from the maneuvering and mobility challenge.
:::

### Dexterity

A dexterity test board. Manipulation tasks. Opening a tube by turning
it.

:::{figure} ../_static/images/history/Dexterity_board.png
:alt: The dexterity test board used in the dexterity challenge.

The dexterity test board.
:::

:::{figure} ../_static/images/history/door.png
:alt: A door-opening and turning task from the dexterity challenge.

A door-opening/turning task from the dexterity challenge.
:::

### Exploration

2D and 3D mapping. Object detection (QR codes, hazmat signs, etc.).
Avoiding holes and difficult terrain. Detecting signs of life.

:::{figure} ../_static/images/history/arena.png
:alt: The competition arena used for the exploration challenge.

The competition arena used for the exploration challenge.
:::

### Readiness

Tests of system sensors and dexterity: video and thermal image
resolution, motion detection, colour pattern recognition, audio
acuity, and similar capability checks.

:::{figure} ../_static/images/history/readiness.png
:alt: The readiness-test setup for sensor and dexterity capability checks.

The readiness-test setup.
:::
