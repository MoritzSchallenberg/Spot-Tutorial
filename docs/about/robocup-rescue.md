# RoboCup Rescue

## Overview

The RoboCup Rescue League challenge categories, as documented by the
former ALeRT tutorial, based on the 2019 rulebook and a subsequent
"smaller teams" ruleset update.

:::{admonition} Historical snapshot
:class: note

## The competition simulates disaster response

A robot must traverse an arena built to resemble a collapsed structure
and demonstrate capability across several categories, which change from
year to year.

## Challenges (2019 rulebook)

### Maneuvering and mobility

Various surfaces. Obstacles.

### Dexterity

A dexterity test board. Manipulation tasks. Opening a tube by turning
it.

### Exploration

2D and 3D mapping. Object detection (QR codes, hazmat signs, etc.).
Avoiding holes and difficult terrain. Detecting signs of life.

### Readiness

Tests of system sensors and dexterity: video and thermal image
resolution, motion detection, colour pattern recognition, audio
acuity, and similar capability checks.

## Updated tasks for smaller teams

A later ruleset update, referenced by the former tutorial, introduced:

- new readiness tests;
- a new arena;
- new terrains;
- a new set of objectives to detect.
